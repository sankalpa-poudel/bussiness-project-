=======
Travel Company — Fullstack Demo

Simple travel company website: vanilla JavaScript frontend and a pure-Java backend HTTP server.

Quick start (Windows):

1. Start the backend server (serves API and the frontend static files):

```powershell
cd "c:\Users\LENOVO\Desktop\bussiness site"
backend\run.bat
```

2. Open the site in your browser: http://localhost:8000/
